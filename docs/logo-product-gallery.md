# 로고와 상품 사진 갤러리

현재 상품 사진은 [2026-10-13 상품별 사진 교체](product-photo-refresh.md)를 적용합니다. 아래 2026-10-12 기록의 채소별 공통 사진 방식은 상품별 구성이 없는 새 상품의 fallback으로 유지됩니다. 로고와 갤러리 조작 방식은 그대로입니다.

2026-10-12, A 조영우.

로고는 2026-10-13 시안 C(단단한 간판)로 교체했습니다(C 이상재). 검은고딕(Black Han Sans, OFL) 글자를 도형으로 바꾼 투명 배경 SVG이며, '이'의 ㅇ을 가운데가 뚫린 찌그러진 못난이 사과로 바꿨습니다. "못난이"는 브랜드 주황(#b4541f), "마켓"은 본문 검정(#333333)입니다. 가로:세로 약 5.4:1로 기존 로고(약 3.2:1)보다 납작해 세로로 길어 보이던 문제를 고쳤습니다.

- 파일: public/brand/motnani-logo.svg (헤더·푸터, BrandLogo), src/app/icon.png (파비콘, 사과만)
- 크기: 높이 기준 320px 24px, 360px 28px, 640px 32px, 데스크톱 40px
- 흰 바탕 전용 색 구성입니다. 어두운 바탕에 쓸 때는 "마켓"을 흰색으로 바꾼 별도 파일이 필요합니다.

2026-10-13 헤더 로고 앞에 동그란 과일 스티커(로고 시안 B "UGLY & GOOD 못난이 MARKET")를 붙이고 파비콘도 스티커로 바꿨습니다(B 심우섭). 글자는 같은 검은고딕(OFL)을 도형으로 바꿔 글꼴 없이도 똑같이 보입니다.

- 파일: public/brand/motnani-sticker.svg (헤더, `BrandLogo withSticker`), src/app/icon.png (파비콘, 512×512 스티커)
- 크기: 높이 기준 320px 28px, 360px 32px, 640px 36px, 데스크톱 44px. 푸터는 글자 로고만 그대로
- 데스크톱 헤더의 로고 칸·아이콘 칸 폭을 256px → 288px로 함께 넓혀 검색창이 가운데에 오게 했습니다.

2026-10-13 스티커 대신 살짝 휜 못난이 당근 마크로 바꿨습니다(B 심우섭, 당근 로고 시안 C). 둥근 몸통·뾰족한 끝·가운데 구멍·초록 잎을 도형으로만 그린 SVG입니다.

- 파일: public/brand/motnani-carrot.svg (헤더, `BrandLogo withMark`), src/app/icon.png (파비콘, 512×512 당근). 스티커 파일은 삭제
- 색: 당근 주황 #e8772e, 잎 초록 #3f8f55
- 크기: 높이 기준 320px 32px, 360px 36px, 640px 44px, 데스크톱 56px

## 상품 사진

기존 인터넷 사진을 재사용해 채소·과일 21종별 사진 묶음을 구성했습니다. 각 상품의 현재 대표사진을 첫 장으로 유지하고 같은 작물의 다른 사진 두 장을 추가합니다. 파일 내용이 같은 사진은 묶음에서 제외했습니다. 같은 작물의 상품들은 보조 사진을 공유할 수 있으며 해당 SKU를 직접 촬영한 세 장이라는 의미는 아닙니다. 기존 사진 이용 조건은 docs/image-sources.md에 있습니다.

- 데이터: src/data/product-gallery.json
- 연결: src/lib/product-gallery.ts
- 목록: ProductImageRotator, 화면에 보이는 사진만 레시피 목록과 동일하게 2초마다 0.7초 페이드로 전환(사진을 겹쳐 미리 불러 둠)하며 사진 위의 표시점은 표시하지 않음. 마우스·키보드 선택, 화면 밖, 백그라운드, 동작 줄이기 설정에서는 멈춤.
- 상세: ProductGallery, 자동 전환 없음. 이전·다음·썸네일·좌우 키로 이동. 3번에서 다음을 누르면 1번으로 돌아감.
- 기존 Supabase 대표사진 URL을 유지하며 보조 사진은 배포에 포함한 로컬 파일로 표시. 파일명이 같은 Storage/로컬 사진을 중복 추가하지 않음. DB 변경이나 SQL 적용 불필요.

## 검증

테스트 53개, lint·typecheck·format:check·build 통과. 모든 활성 상품에 서로 다른 사진 세 장을 연결하는 검사 및 실제 파일 해시 검사를 통과했습니다. 1280px 상세의 이전·다음·썸네일 순환, 목록의 1번→2번 자동 전환, 390/320px 로고·상세 화면의 가로 넘침 없음 확인. 실제 공유 DB 접속과 실기기 검수는 별도입니다.
