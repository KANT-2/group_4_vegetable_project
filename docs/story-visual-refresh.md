# 농가 이야기 사진 중심 개편 (2026-10-12)

A 조영우 담당. `/story`에서 긴 소개 글을 먼저 읽어야 농가 사진을 볼 수 있던 구조를 바꿨습니다.

- 상단: 농산물 사진 3장, 짧은 제목과 소개, 농가 목록으로 바로 이동하는 버튼.
- 모바일: 사진 → 짧은 소개 → 사진이 있는 농가 카드 1열. PC: 상단 좌우 배치와 농가 카드 2열.
- 순서: 농가 카드 먼저, 서비스 가치·이용 순서·못난이 이유 설명은 이후.
- 농가 카드: 사진·지역·짧은 이야기·상품/레시피 연결. 각각 3개까지 먼저 표시하고 나머지는 더 보기로 모두 접근 가능.
- 못난이 이유: 해당 유형의 상품 사진과 펼쳐 읽는 설명. 기존 전체 농가 더 보기와 `#about` 링크 유지.

사진은 기존 상품 참고 이미지이며 실제 해당 농가를 촬영한 것으로 표시하지 않습니다. 농가 이야기의 시연 데이터 안내를 유지하고 새 농가 사실·인터뷰를 만들지 않았습니다. 사진 출처는 [기존 이미지 출처](image-sources.md)를 따릅니다. DB나 환경변수 변경은 없습니다.

검증: 390px/360px 모바일 가로 넘침 없음, 사진 로드와 농가 이동·상품 더 보기 확인. PC 1280px 배치 확인. lint·typecheck·format:check·build와 기존 테스트 실행 결과를 PR에 기록합니다. 실제 팀 DB와 휴대폰 실기기 검수는 별도입니다.

캡처: `docs/screenshots/story-mobile.png`, `story-desktop.png`, `story-farm-mobile.png`.

## 농작업·농장 사진 적용

큰 농산물 사진을 실제 한국 농작업/농장 풍경 3종으로 바꾸고, 상품 사진은 작은 썸네일로 줄였습니다. 상단은 농작업 장면과 짧은 소개로 구성합니다. 사진 속 농장을 시연 농가의 실제 현장으로 소개하지 않으며 [작가·출처](farm-photo-sources.md)를 페이지 아래 접힌 출처에 표시합니다.
