# 못난이마켓 작업 요약

2026-10-13 · Git main 변경 내역과 저장소 문서를 기준으로 정리했습니다. 확인 시점에 상단 메뉴와 README 정리까지 main에 반영됐습니다. 품목·페이지·사진 개수보다 구현한 기능과 문제 해결 과정을 기록합니다.

## 기획과 공통 기반

비규격 농산물을 소개하고 채소 활용 방법까지 연결하는 서비스로 범위를 정했습니다. 레시피 목록·상세·데이터는 A, 상품·채소 정보는 B, 인증·개인 저장·공통 DB는 C가 기능 단위로 담당했습니다. 화면과 백엔드는 Next.js·Supabase로 통일했습니다.

공통 폴더·화면용 타입·경로·디자인 규칙·ERD·권한 기준을 맞춘 뒤 Mock 데이터로 각 화면을 구현하고 공유 DB·공통 메뉴와 통합했습니다. Redmine에는 기능별 작업을, Notion에는 개인 진행 과정을 기록하는 협업 흐름을 사용했습니다.

## 공개 화면과 데이터

A가 공식 레시피의 재료·조리 단계·채소 관계를 정리하고 카탈로그 생성·검증 도구와 migration·seed를 작성했습니다. 원문에 없는 조리시간·난이도를 추정하지 않았습니다. B는 상품·채소 조회와 검색·필터·정렬, 가격·못난이 이유·제철·보관·영양 정보를 구현했습니다.

상품 → 채소 정보 → 레시피 → 관련 상품 이동을 통합했습니다. 배포 중 레시피 컬럼 누락은 공유 DB와 migration·seed 적용 기록을 확인해 해결했습니다. 채소 상세의 충돌은 영양 카드 → 레시피 → 상품 순서로 정리했습니다.

## 인증과 개인 기능

C가 Google 로그인·callback·세션 갱신·로그인 복귀 경로와 프로필·기본 배송지·사용자별 장바구니·찜을 구현했습니다. 개인 변경은 서버에서 확인한 사용자와 RLS를 기준으로 처리합니다.

장바구니에서 배송지와 결제 수단을 선택하고 주문 내역·상세로 이동하는 모의 결제 흐름을 추가했습니다. DB에서 판매 상태·가격·수량·배송비를 검증하고 주문 당시 내용을 저장합니다. 중복 요청에는 기존 주문을 반환합니다. 실제 PG·배송·환불 송금은 별도 범위입니다.

## 사진·디자인·모바일 개선

레시피 사진 중복과 부적절한 음식 사진, 작물과 맞지 않는 농장 사진을 교체했습니다. 농가 화면은 긴 소개보다 사진·지역·농가별 상품을 먼저 보여주도록 개선했습니다. B가 농가별 사진과 상세 이야기를 보완하고 C가 상품별 사진과 레시피 카드 연결 경로를 수정했습니다.

A가 상품 카드 사진 자동 페이드·상세 수동 전환과 마이페이지·결제·주문 상세의 정보 구획·모바일 배치를 개선했습니다. 로고는 A의 초기 제안 이후 C·B의 워드마크·농산물 심볼 개선으로 현재 형태에 통합됐습니다. 모바일 메뉴와 필터에는 잘린 항목을 알리는 화살표를 적용하고 불필요한 홈 바로가기·중복 제목·설명을 정리했습니다.

## 행사와 프로모션

C가 메인 행사 배너를 통합했고 A가 전환 간격을 3초로 바꿨습니다. 오픈런·첫 구매·배송·김장 할인·가족 체험별 상세를 추가하고 메인에서 누른 배너가 상세에서도 동일하게 유지되도록 수정했습니다.

혜택 조건·일정·참가비는 사용자 승인으로 작성한 기획안입니다. 실제 발급·할인·접수는 준비 상태로 표시합니다. 행사 목록은 main에 반영됐고 상단·모바일 메뉴 진입은 PR #69에서 구현했습니다.

## 쿠폰 발급·보관 후속 구현

불필요한 별도 혜택 보기 버튼을 제거하고 실제 세션을 사용하는 쿠폰 발급 Action과 DB 함수를 추가했습니다. 행사 기간·첫 구매·한국 시간 오픈런·중복을 DB에서 검증하며 쿠폰 테이블 직접 쓰기는 허용하지 않습니다. 장바구니 내 쿠폰 탭에서 보유·만료 상태를 조회합니다. 자동 권한 테스트와 공유 DB 적용을 완료했습니다. 실제 DB에서도 발급·중복·계정 분리를 확인한 뒤 테스트 데이터를 rollback했습니다. 결제 할인 적용은 별도입니다. [구현·검증·적용 상태](coupons.md).
