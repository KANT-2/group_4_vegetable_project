## 변경

- 메인 배너는 3초 간격으로 전환합니다. 700ms 페이드와 일시정지, 호버·포커스·동작 줄이기 동작을 유지합니다.
- 오픈런 쿠폰, 첫 구매, 배송 안내, 김장 쿠폰, 가족 김장체험 배너가 각각 `/promotions/[slug]` 상세 화면으로 이동합니다.
- 컬리의 행사 이미지 → 혜택 조건 → 상품 진열 → 이용 안내 흐름을 참고하고 기존 테라코타 색상을 유지했습니다.
- 웹·모바일 공통 화면, 페이지 내 이동 메뉴, 관련 실제 상품 연결, 행사 목록과 메타데이터를 제공합니다.

## 구현 범위

프로모션 안내·상품 연결과 계정별 쿠폰 발급·쿠폰함 코드를 구현했습니다. 쿠폰 DB migration은 2026-10-13 공유 환경에 적용했습니다. 결제 할인·사용 처리와 실제 체험 접수·결제는 아직 없습니다. [쿠폰 구현·조건·적용 상태](coupons.md)를 확인하세요.

## 상세 상단 배너 통일

상세 화면의 별도 제목·사진 분할 히어로를 제거하고 홈에서 선택한 배너를 동일한 이미지, 문구, 비율, 모바일 크롭으로 유지합니다. 상세 배너는 자동 전환되지 않으며 별도의 혜택 보기 버튼은 제거했고, 배너 자체와 페이지 내 메뉴를 누르면 조건 영역으로 이동합니다. 홈과 상세가 함께 사용하는 배너 설정은 `src/data/home-campaigns.ts`에서 관리합니다.
