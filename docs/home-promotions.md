# 홈 배너와 프로모션 상세 화면

2026-10-13 · A 조영우

## 변경

- 메인 배너는 3초 간격으로 전환합니다. 700ms 페이드와 일시정지, 호버·포커스·동작 줄이기 동작을 유지합니다.
- 오픈런 쿠폰, 첫 구매, 배송 안내, 김장 쿠폰, 가족 김장체험 배너가 각각 `/promotions/[slug]` 상세 화면으로 이동합니다.
- 컬리의 행사 이미지 → 혜택 조건 → 상품 진열 → 이용 안내 흐름을 참고하고 기존 테라코타 색상을 유지했습니다.
- 웹·모바일 공통 화면, 페이지 내 이동 메뉴, 관련 실제 상품 연결, 행사 목록과 메타데이터를 제공합니다.

## 구현 범위

이번 변경은 프로모션 안내 및 상품 연결입니다. 쿠폰 DB 발급, 주문 RPC 할인 검증, 실제 체험 접수·결제 기능은 없습니다. 발급·예약 준비 상태를 명시하고 완료 메시지나 허위 예약을 만들지 않습니다. 체험 장소와 실제 배송 일정을 확정된 운영 사실처럼 표시하지 않습니다. 서버 발급과 결제 할인 기능을 연결하기 전에는 준비 상태를 유지해야 합니다.
