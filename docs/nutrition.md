# 채소 영양 정보 출처

채소 정보 화면(`/vegetables/[id]`)의 "영양 정보" 칸은 두 파일을 합쳐서 보여 줍니다. 모두 **생것, 가식부 100g 기준**입니다.

| 파일                               | 담당              | 채소                                     |
| ---------------------------------- | ----------------- | ---------------------------------------- |
| `data/food-catalog/nutrition.json` | A (영우) 카탈로그 | 감자·당근·양파·애호박·가지·파프리카(4색) |
| `data/nutrition/fct-2006-b.json`   | B (우섭)          | 나머지 15종                              |

## 출처

- 농촌진흥청 식품성분표 제7개정판 제I편(2006), FAO 배포 PDF (`sources.json`의 `fct-2006`)
- 2026-10-12 내려받은 PDF의 SHA-256이 카탈로그 기록과 같음: `3c1be0d1501a210a13236f1044b6a7543e35ae09b1a1aa81763291b7e2a8b6df`
- 값은 PDF 표를 쪽 단위로 직접 보고 옮겼습니다 (`verification: pdf_table_visually_checked`). 쪽 번호는 PDF 1부터 센 번호입니다.
- 카탈로그와 같이 `Fiber`는 조섬유라 식이섬유(`dietary_fiber_g`)에 넣지 않았습니다. 표의 `Ø`(미량)는 값을 비우고 `*_value_status: "trace"`로 표시합니다. `-`(측정값 없음)도 비웁니다.
