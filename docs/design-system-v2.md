# 디자인 규칙 v2 (2026-10-12, A 조영우)

> 마켓컬리 화면 구조를 기준으로 다시 정한 공통 디자인 규칙입니다. 기존 규칙은 [design-guide.md](design-guide.md)에 있고, 이 문서가 바뀐 부분을 우선합니다.
> 팀 보고서: [redesign-v2-report.md](redesign-v2-report.md)

## 1. 기준

- **배치·카드 형식·글꼴**: 마켓컬리(kurly.com) 메인·상품 상세를 측정해 맞췄습니다.
- **색**: 컬리의 보라색은 컬리 고유 브랜드라 쓰지 않고, 흙과 햇빛 느낌의 **테라코타(갈색과 주황 사이)** 로 정했습니다.
- **접근성**: 글자 대비 4.5:1 이상, 버튼 높이 40px 이상, 키보드 초점 표시는 그대로 지킵니다.

## 2. 글꼴

- **Pretendard** (마켓컬리와 같은 글꼴, SIL Open Font License)
- `pretendard` 패키지의 **동적 부분 집합**을 `src/app/layout.tsx`에서 불러옵니다. 화면에 쓰인 글자 묶음만 내려받아 2MB 전체 파일보다 가볍고, 외부 CDN 없이 우리 서버에서 제공돼요.
- 불러오지 못하면 시스템 한글 글꼴(Apple SD Gothic Neo, 맑은 고딕)로 같은 구조를 유지합니다.
- 굵기: 제목 500~700, 본문 400. 800~900은 로고에만 씁니다.

## 3. 색 (`src/app/globals.css`)

| 이름         | 값        | 쓰는 곳                                     | 대비(흰 바탕)   |
| ------------ | --------- | ------------------------------------------- | --------------- |
| `canvas`     | `#FFFFFF` | 페이지 배경                                 | —               |
| `sand`       | `#F7F7F7` | 구역 배경, 이미지 자리, 띠 배너             | —               |
| `ink`        | `#333333` | 본문                                        | 12.6 : 1        |
| `ink-muted`  | `#767676` | 보조 설명, 정가, 후기 수                    | 4.5 : 1         |
| `line`       | `#DDDDDD` | [담기]·입력창·구분선                        | —               |
| `brand`      | `#B4541F` | 로고, 주요 버튼, 선택된 메뉴, 검색창 테두리 | 흰 글자 5.0 : 1 |
| `brand-dark` | `#7A3A12` | 진한 글자·링크                              | 8.6 : 1         |
| `brand-soft` | `#FBF1E9` | 연한 주황 면, 안내 띠, 선택된 항목          | —               |
| `accent`     | `#D9381E` | **할인율에만**                              | 4.6 : 1         |

- 색 이름은 그대로라 B·C 화면 코드는 고치지 않아도 새 색이 적용됩니다.
- 색을 직접 쓰지 말고 이름(`bg-brand`, `text-ink-muted` …)으로만 씁니다.

## 4. 모서리·그림자·폭

- 본문 폭 **1050px** (`container-page`, 좌우 여백 포함 최대 1098px)
- 버튼 `.btn` 모서리 **4px**(알약 모양 → 각진 버튼), 카드 8px, 상품 사진 4px
- 그림자는 헤더 아래 `0 3px 4px rgb(0 0 0 / 7%)`와 카드의 아주 옅은 한 단계만

## 5. 사진

- 밝고 깨끗한 사진: 자연광, 흰 배경이나 밝은 나무·천 위
- 피할 것: 흙이 많은 사진, 어두운 배경, 밭·통나무 위, 상한 것처럼 보이는 접사
- 못난이 특징은 사진이 아니라 **꼬리표**(`휘어졌어요`, `흠집 있어요`)로 알립니다
- 상품 사진은 800×800으로 저장하고 카드에서는 249×320 비율로 잘라 보여줍니다
- 배너에는 가로로 긴 사진(1600px 이상)만 화면 가득 씁니다. 없으면 연한 배경 + 오른쪽 정사각형 사진 형식
- 출처·라이선스는 화면에 표시하지 않고 [image-sources.md](image-sources.md)에 기록합니다

## 6. 헤더 (`SiteHeader`)

| 줄                  | PC                                                                                          | 휴대폰                               |
| ------------------- | ------------------------------------------------------------------------------------------- | ------------------------------------ |
| 1. 회원 메뉴        | 오른쪽 위 12px: `회원가입 \| 로그인` / 로그인 후 `닉네임님 \| 마이페이지 \| 로그아웃`       | 햄버거 메뉴 안                       |
| 2. 로고·검색·아이콘 | 로고 / 가운데 검색창 400×48 / 찜·장바구니(개수)                                             | 로고 + 찜·장바구니·메뉴, 아래 검색창 |
| 3. 메뉴             | `☰ 카테고리` + 전체 상품·제철·특가·대용량·1인 가구·레시피·농가 이야기 + `못난이 선별 기준` | 옆으로 넘기는 탭                     |

로그인 상태·장바구니 개수·로그아웃은 기존 `useNavigation`·`signOut`을 그대로 씁니다.

## 7. 구역 제목과 진열 줄 (`HomeShelf`)

- 가운데 정렬 제목 28px(휴대폰 22px) + `›`, 아래 회색 설명 16px
- 4개씩 보이는 가로 줄, 카드 간격 18px, 지름 60px 흰 원 화살표
- 휴대폰은 2.3개가 보이고 손가락으로 넘깁니다

## 8. 상품 카드 (`ProductPreviewCard`, 상품 목록 `ProductCard`도 같은 카드)

순서: **사진(249×320) → [담기] → `[농가] 상품명` → 홍보 문구 → 정가(취소선) → 할인율 + 판매가 → 💬 후기 수**

- [담기]: 높이 40px, 테두리 `line`, 누르면 1개 담기(로그인 전이면 로그인 후 돌아옴)
- 상품명 16px 2줄, 정가 14px `ink-muted`, 할인율·가격 16px 굵게

## 9. 화면별 구성

- **메인**: 화면 너비 사진 배너(370px) → 채소 바로가기 → 💸 할인 → 🍂 제철 → 띠 배너 → 🏆 후기 많은 → 🙋 1인 가구 → 🧺 대용량 → 🍳 레시피 → 🌾 농가
- **농가 이야기** `/story`: 사진 배너 → 농가 카드 목록(누르면 상세) → 서비스 소개 → 못난이 이유
- **농가 상세** `/story/[농가 이름]`: 사진·소개·한눈에 보기 → 탭(판매 상품 | 농가 위치 | 요리) → 판매 상품 → **구글 지도** → 이 채소로 만드는 요리 → 다른 농가
- **상품 목록·상세, 레시피, 채소, 장바구니, 로그인, 마이페이지**: 색·글꼴·버튼·카드 규칙이 자동 적용됩니다
