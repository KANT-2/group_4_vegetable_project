# 제철 과일 첫 화면과 추천 규칙 (2026-10-12)

담당: A 조영우. 상품 목록의 공통 정렬 기능도 함께 개선했으며 B의 상품 데이터는 유지했습니다.

## 첫 화면

메인(`/`)과 마켓 기본 목록(`/products`) 맨 위에 제철 과일 캐러셀을 표시합니다. 판매 중(`isActive`)이고 제철(`isSeasonal`)이며 과일(`category=fruit`)인 상품을 실제 할인율순으로 최대 6개 선정합니다. 현재 시연 카탈로그에서는 사과 3개가 해당하며, 제철 표시가 없는 귤은 넣지 않습니다. 지역별 수확기 자동 판정이 아닌 상품 정보 기준입니다. 적격 상품이 없으면 배너를 숨깁니다. 상품 담당자는 제철 여부와 판매가를 상품 데이터에서 관리합니다.

5초마다 사진·상품명·할인율·판매가·원가·단위가 함께 바뀝니다. PC는 설명과 사진을 좌우 배치하고 모바일은 사진 아래에 가격을 표시합니다. 이전/다음, 위치 선택, 재생 정지/시작, 터치 스와이프를 지원합니다. 키보드로 배너에 포커스를 둔 후 좌우 화살표로 이동할 수 있습니다. 마우스 진입·포커스·탭 비활성화 중에는 자동 재생을 멈춥니다. 동작 줄이기 환경에서는 자동 재생과 전환 효과를 끕니다. 필터를 적용한 목록에서는 배너를 숨겨 검색 결과를 먼저 보여줍니다.

## 정렬 규칙

| 선택             | 우선순위                                                    |
| ---------------- | ----------------------------------------------------------- |
| 추천순           | 운영 추천(isFeatured) → 제철 → 실제 할인율 → 낮은 가격 → ID |
| 제철순           | 제철 → 실제 할인율 → ID                                     |
| 할인순           | 실제 할인율 → ID                                            |
| 낮은/높은 가격순 | 판매가 → ID                                                 |
| 리뷰순(시연)     | 리뷰 수 → ID                                                |

할인율은 `(원가-판매가)/원가`로 비교하고 화면에만 반올림합니다. 동률은 상품 ID로 안정적으로 정렬합니다. 메인 추천 카드는 먼저 채소 종류가 겹치지 않도록 고른 뒤 부족한 수량을 채웁니다. 판매하지 않는 상품은 추천 후보에서 제외합니다. DB 컬럼 추가는 필요하지 않습니다.

현재 리뷰 수는 시연 데이터이므로 리뷰순에 안내를 붙였습니다. 실제 결제 완료 주문 집계가 없어 구매순·인기순을 판매 실적인 것처럼 제공하지 않습니다. 향후 주문 집계 기준(결제 완료, 취소 제외, 집계 기간)을 합의한 다음 추가합니다.

## 레시피 사진

공식 레시피 16개에 Wikimedia Commons 사진 10개를 연결했습니다. 실제 해당 레시피의 조리 결과가 아닌 **유사 요리 참고 사진**입니다. 카드와 상세 화면에 이를 명시하고 사진 표시 페이지에 작가·출처·라이선스를 제공합니다. 상세 사진이 DB에 있으면 그 사진을 우선하며 정적 참고 이미지로 덮어쓰지 않습니다. 새로운 DB migration이나 Storage 업로드는 하지 않았습니다.

사진 파일은 `public/images/recipes`, 출처 메타데이터는 `src/data/recipe-photo-assets.json`, 레시피별 연결은 `src/lib/recipe-photos.ts`입니다. [사진 출처와 사용 조건](recipe-photo-sources.md)을 확인하세요. 이전에 보류한 농사로 원문 사진 후보와 별도의 자료입니다.

## 확인과 남은 범위

로컬 시연 모드에서 PC·모바일(360px/390px) 배치, 자동 재생/정지, 직접 넘기기 및 상품 상세 이동을 확인했습니다. 최신 main(상품 검색·마이페이지·환불)을 통합한 후 테스트 28개·lint·typecheck·format:check·build가 통과했습니다. 실제 팀 Supabase 연결, 배포 환경, 실제 휴대폰 터치 검수는 별도로 남아 있습니다. 상품 제철 정보는 운영자가 갱신해야 합니다. 캡처는 `docs/screenshots`에 기록합니다.

최신 팀 상품 검색창·코너 메뉴를 함께 유지했고 검색어가 있으면 배너를 숨깁니다. [PR #19](https://github.com/KANT-2/group_6_vegetable_project/pull/19)에서 검토할 수 있습니다.

## 사진 강조 배너 조정 (2026-10-12)

PC 배너 폭을 최대 1440px로 넓히고 설명:사진을 1:2 비율로 배치했습니다. PC 높이는 512~576px이며 모바일 사진은 288~416px 높이로 확대했습니다. 정보·사진·버튼을 함께 유지하며 기존 5초 전환과 정지/넘기기 기능은 유지합니다. 상품 목록의 나머지 카드 폭은 그대로 유지합니다.
