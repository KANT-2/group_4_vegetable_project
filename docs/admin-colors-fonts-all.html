관리자 전체 화면 색상·폰트 정리

기준일: 2026-10-26. 현재 저장소의 CSS와 관리자 화면 컴포넌트를 기준으로 작성했습니다. 실제 코드를 변경하지 않고 사용 중인 스타일만 정리했습니다. 크기는 브라우저 기본 글자 크기 16px 기준이며, 확대 비율에 따라 화면에서 보이는 크기는 달라집니다.

투명도·상호작용

  • 팝업 뒤 배경: 검정 #000000, 불투명도 20%·25%·30%·35%. 창 종류별로 다릅니다.
  • 상품 행 호버: bg-sand/60, 즉 #F7F7F7의 60% 불투명도.
  • 이벤트 편집 구분선: border-brand/30, 즉 브랜드색 30% 불투명도.
  • 비활성 공통 버튼: 배경·테두리 #E6E9E5, 글자 #626A64.
  • 공통 .field placeholder: #7A756C. 단, .field가 아닌 개별 입력은 브라우저 기본 placeholder 표시를 사용할 수 있습니다.
  • 키보드 포커스: 브랜드색 3px 외곽선, 요소에서 3px 간격.

4. 글꼴

기본 글꼴은 Pretendard Variable입니다. src/app/layout.tsx에서 패키지의 동적 서브셋 CSS를 불러옵니다. 관리자 전용의 다른 본문 글꼴은 지정하지 않았습니다.

font-family:
  "Pretendard Variable", "Pretendard", "Apple SD Gothic Neo", "Noto Sans KR",
  "Malgun Gothic", "맑은 고딕", system-ui, sans-serif;

체험 예약 운영 화면의 사용자 ID 일부는 예외적으로 font-mono를 사용합니다. 운영체제의 기본 고정폭 글꼴로 표시되며 특정 한글 폰트를 지정한 것은 아닙니다.

로고 /brand/motnani-admin-wordmark.png의 글씨는 이미지입니다. Pretendard로 입력한 텍스트가 아니며, 코드만으로 로고 원본 서체명을 확정할 수 없습니다.

7. 현재 혼용되는 부분

  • 성공색은 브랜드 토큰이 아니라 Tailwind 초록색을 직접 사용합니다.
  • 오류는 danger와 red-700이 함께 사용됩니다.
  • 입력 테두리는 line과 field-border 두 종류입니다.
  • 표 헤더 gray-50과 본문 배경 sand는 서로 다른 연회색입니다.
  • 따라서 현재 화면을 그대로 재현하려면 모든 회색·빨강을 한 값으로 통일하지 않아야 합니다.
