# 채소 중심 집밥 레시피

2026-10-12, A 조영우.

## 구성

기존 공식 레시피 16개를 보존하고 직접 작성한 간단한 집밥 24개를 먼저 표시합니다. 감자·당근·애호박·가지·양파·양배추·오이·시금치·브로콜리·무·표고버섯·토마토를 주재료로 각각 2개씩 제공합니다. 고기·면 위주 요리 대신 반찬·달걀 요리·덮밥·국으로 구성했습니다.

모두 2인분, 쉬움, 준비 포함 예상 10~25분입니다. 양파 달걀덮밥의 밥은 미리 지은 밥 기준입니다. 조리 시간은 편집 추정이며 직접 조리 실측을 마친 수치는 아닙니다. 일반 조미료와 구체적인 분량, 3단계 조리법을 기록했습니다. 공식 원문을 가져온 것으로 표시하지 않습니다. 공식 16개는 기존 출처 링크와 미기재 시간·난이도를 유지합니다.

## 연결과 표시

`src/data/easy-recipes.json`이 편집 원본입니다. `primaryVegetableId`로 필터·관련 레시피를 분류합니다. 토마토 양파샐러드는 양파 재료 및 양파 상품도 연결하지만 주재료 분류는 토마토입니다. 상품과 채소 상세의 기존 레시피 조회 함수에서도 새 요리를 표시합니다. 모바일 필터는 가로 스크롤, PC는 줄바꿈합니다.

Mock에서는 Mock 상품, Supabase에서는 판매 중인 실제 DB 상품을 채소 ID로 연결합니다. 상품이 없는 채소도 레시피는 유지하며 없는 상품을 만들지 않습니다. 편집 데이터는 배포에 포함되므로 SQL 추가 적용 없이 두 모드에서 표시됩니다. DB 조회 실패를 Mock으로 덮지 않으며 공식 DB 레시피는 그대로 읽습니다. 기존 음식 카탈로그·공식 시드·마이그레이션은 수정하지 않았습니다. 동일 ID는 편집본을 우선해 중복 표시하지 않습니다.

## 사진

사용자 요청에 따라 추가 사진 생성은 중단하고 새 레시피에는 인터넷 사진을 사용합니다. 감자채볶음·애호박전·당근라페·오이무침·토마토 달걀볶음은 CC0 요리 사진을 사용하며 나머지는 기존 무료 사용 이미지의 해당 주재료 사진을 연결합니다. 새 사진 생성 결과는 프로젝트에 넣지 않았습니다. 주재료 사진은 대체 텍스트에서도 완성 요리 사진과 구분합니다. 화면의 사진 출처 패널은 제거했습니다.

## 검증

콘텐츠 및 연결 테스트에서 주재료·분량·단계·이미지 파일·비활성 상품 제외·실제 상품 ID 연결·상품 없는 채소 보존·주재료 필터·공식 레시피 보존·중복 방지를 검사합니다. 실제 공유 DB 접속과 실기기 조리 검수는 별도입니다.

최종 검증: 테스트 40개, lint·typecheck·format:check·build 통과. 모바일 390px에서 화면 넘침 없음, 총 40개 표시와 당근 필터 확인. 캡처: docs/screenshots/easy-recipes-mobile.png. 공유 DB 접속 검수는 수행하지 않았습니다.

## 사진·모바일 후속 수정 (2026-10-12)

인터넷 요리 사진 16개를 추가하고 반복되던 표고버섯 사진을 다른 사진으로 연결했습니다. 전체 40개 레시피의 이미지 URL과 실제 파일 SHA-256이 모두 서로 다릅니다. 사진 출처 패널은 표시하지 않습니다. 모바일 필터는 상품 화면의 ScrollRow를 재사용해 가로 탭·선택 밑줄·넘기기 화살표로 표시합니다. 검색·선택 상태는 URL로 유지합니다. 영주 사과마을의 큰 과수원 사진과 작은 상품 사진도 함께 교체했습니다. 별도 SQL 적용은 필요 없습니다.
