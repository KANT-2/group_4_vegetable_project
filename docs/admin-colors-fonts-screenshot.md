# 첨부 이미지의 색상·폰트 정리

기준일: 2026-10-26. 사용자가 첨부한 **상품 관리 화면 일부 이미지**에 보이는 요소만 정리했습니다. 이미지 밖의 버튼·상태·팝업·다른 관리자 화면은 포함하지 않습니다.

색상과 글자 크기는 이미지와 대응하는 현재 코드에서 확인한 값입니다. 이미지 픽셀을 직접 추출한 결과가 아니므로, 캡처 확대·축소와 압축에 따른 차이는 있을 수 있습니다.

### 초록색 수정 완료 알림

| 요소 | 원본 색상 값 | 코드 |
| --- | --- | --- |
| 연한 초록 배경 | `oklch(98.2% 0.018 155.826)` | `bg-green-50` |
| 초록 테두리 | `oklch(92.5% 0.084 155.995)` | `border-green-200` |
| ‘상품 정보가 수정되었습니다.’ 글자 | `oklch(44.8% 0.119 151.328)` | `text-green-800` |

초록색은 설치된 Tailwind v4의 원본 OKLCH 값을 적었습니다. 이미지에서 보이는 색을 임의 HEX로 확정하지 않았습니다.

### 로고 색상

로고는 `/brand/motnani-admin-wordmark.png` 이미지입니다. 갈색·주황 계열 글씨와 초록 잎이 보이지만, CSS의 `brand`·성공색을 적용한 요소는 아닙니다. 이미지 원본 색상을 따로 확인하지 않고 정확한 HEX 값을 단정할 수 없습니다.

검색창 안내 글씨는 연회색 placeholder입니다. 이 입력은 공통 `.field` 대신 개별 클래스를 사용하므로, `.field::placeholder`의 `#7A756C`를 그대로 적용한 것으로 해석하면 안 됩니다. 현재 코드에는 이 검색창 placeholder 색상의 별도 고정값이 없습니다.

## 2. 폰트

이미지의 일반 UI 글자는 **Pretendard Variable**을 사용하도록 설정돼 있습니다. 로고 글씨는 예외적으로 이미지이며 원본 서체명은 코드에서 확인되지 않습니다.

글꼴 대체 순서:

```css
"Pretendard Variable", "Pretendard", "Apple SD Gothic Neo", "Noto Sans KR",
"Malgun Gothic", "맑은 고딕", system-ui, sans-serif
```

## 3. 이미지에 보이는 글자 규격

아래는 캡처에서 재어 추정한 크기가 아니라 **대응 코드의 CSS 크기**입니다. 캡처에서 더 크게 보이는 것은 화면 배율 등의 영향을 받을 수 있습니다.

| 요소 | CSS 크기 | 굵기 |
| --- | --- | --- |
| ‘상품 관리’ 큰 제목 | 데스크톱 36px / 모바일 28px | 800 |
| 왼쪽 메뉴 항목 | 16px 기본 | 700 |
| ‘관리자 메뉴’ 구역명 | 12px | 700 |
| 제목 아래 설명 | 16px 기본 | 400 |
| 수정 완료 알림 문구 | 14px | 400 |
| 검색창 입력·안내 | 16px | 400 |
| ‘전체 71개 상품’ | 16px 기본 | 기본 400 / 숫자 700 |
| ‘상품 ID’ 표 헤더 | 14px | 600 |

제목 자간은 -0.02em입니다. 전체 기본 행간은 1.7이며 `text-sm`, `text-base`가 지정된 요소에는 해당 Tailwind 행간이 함께 적용됩니다.

## 4. 이 이미지의 스타일을 재현할 때

- 본문은 연회색, 헤더·사이드바·입력은 흰색으로 구분합니다.
- 선택된 메뉴에만 연한 주황 배경과 테라코타 글자·아이콘·왼쪽 표시선을 사용합니다.
- 제목은 진한 회색·두꺼운 글꼴, 설명과 비선택 메뉴는 보조 회색을 사용합니다.
- 성공 알림은 초록 계열이며 브랜드 주황색과 역할을 구분합니다.
- 로고는 원본 PNG를 사용해야 같은 모양이 됩니다.

## 5. 확인 근거

- `src/app/globals.css`: 브랜드·배경·글자·선 색상, 기본 폰트, 제목 규격
- `src/app/layout.tsx`: Pretendard Variable 로딩
- `src/components/admin/AdminProducts.tsx`: 메뉴·알림·검색·목록·로고
- `node_modules/tailwindcss/theme.css`: 초록 알림과 회색 표 헤더의 원본 색상
