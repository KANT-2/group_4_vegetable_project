# 관리자 전체 화면 색상·폰트 정리

기준일: 2026-10-26. 현재 저장소의 CSS와 관리자 화면 컴포넌트를 기준으로 작성했습니다. 실제 코드를 변경하지 않고 사용 중인 스타일만 정리했습니다. 크기는 브라우저 기본 글자 크기 16px 기준이며, 확대 비율에 따라 화면에서 보이는 크기는 달라집니다.

## 1. 확인 범위

| 화면 | 경로 | 확인한 구성 |
| --- | --- | --- |
| 상품 관리 | `/admin` | 헤더·사이드바·검색·필터·목록·상태·페이지 이동·상품 등록·수정 |
| 레시피 관리 | `/admin/recipes` | 목록·등록·수정·이미지 선택·삭제 확인 |
| 농가 관리 | `/admin/farms` | 지역 탭·카드·등록·수정 |
| 혜택·이벤트 관리 | `/admin/promotions` | 목록·공개 상태·등록·수정·쿠폰 미리보기 |
| 휴지통 | `/admin/trash` | 분류·목록·복원·영구 삭제 |
| 관리자 마이페이지 | `/admin/mypage` | 내 정보·비밀번호 변경·성공·오류 안내 |
| 관리자 로그인 | `/admin/login` | 로그인 입력·오류·관련 링크 |
| 관리자 가입 | `/admin/signup`, `/admin/signup/complete` | 입력·검증·가입 안내 |

| 공통 팝업 | 위 화면 내부 | 확인 창·편집 창·모바일 메뉴·저장 알림 |

체험 예약 운영 화면은 `/admin` 관리 화면과 레이아웃이 다르지만 같은 전역 색상·글꼴을 사용하므로 포함했습니다. 고객 페이지 전용 스타일과 상품 사진·이벤트 이미지 내부 색상은 제외했습니다.

## 3. 상태·보조 색상

아래 값은 설치된 Tailwind CSS의 `node_modules/tailwindcss/theme.css` 기준입니다. Tailwind v4는 OKLCH로 정의하므로 이를 원본 값으로 기재합니다. 예전 Tailwind 버전의 HEX 값을 그대로 대입하면 차이가 생길 수 있습니다.

| 클래스 | 원본 색상 값 | 사용 용도 |
| --- | --- | --- |
| `bg-green-50` | `oklch(98.2% 0.018 155.826)` | 저장 성공 알림·판매 상태 배경 |
| `border-green-200` | `oklch(92.5% 0.084 155.995)` | 성공 알림 테두리 |
| `text-green-800` | `oklch(44.8% 0.119 151.328)` | 성공 알림·상태 글자 |
| `text-green-700` | `oklch(52.7% 0.154 150.069)` | 일부 정상 상태 글자 |
| `bg-gray-50` | `oklch(98.5% 0.002 247.839)` | 상품·레시피·이벤트·휴지통 표 헤더 |
| `bg-gray-100` | `oklch(96.7% 0.003 264.542)` | 판매 중지 등 상태 배경 |
| `text-gray-600` | `oklch(44.6% 0.03 256.802)` | 비활성 상태 글자 |
| `text-red-700` | `oklch(50.5% 0.213 27.518)` | 일부 편집 폼 오류 |

### 투명도·상호작용

- 팝업 뒤 배경: 검정 `#000000`, 불투명도 20%·25%·30%·35%. 창 종류별로 다릅니다.
- 상품 행 호버: `bg-sand/60`, 즉 `#F7F7F7`의 60% 불투명도.
- 이벤트 편집 구분선: `border-brand/30`, 즉 브랜드색 30% 불투명도.
- 비활성 공통 버튼: 배경·테두리 `#E6E9E5`, 글자 `#626A64`.
- 공통 `.field` placeholder: `#7A756C`. 단, `.field`가 아닌 개별 입력은 브라우저 기본 placeholder 표시를 사용할 수 있습니다.
- 키보드 포커스: 브랜드색 3px 외곽선, 요소에서 3px 간격.

## 4. 글꼴

기본 글꼴은 **Pretendard Variable**입니다. `src/app/layout.tsx`에서 패키지의 동적 서브셋 CSS를 불러옵니다. 관리자 전용의 다른 본문 글꼴은 지정하지 않았습니다.

```css
font-family:
  "Pretendard Variable", "Pretendard", "Apple SD Gothic Neo", "Noto Sans KR",
  "Malgun Gothic", "맑은 고딕", system-ui, sans-serif;
```

체험 예약 운영 화면의 사용자 ID 일부는 예외적으로 `font-mono`를 사용합니다. 운영체제의 기본 고정폭 글꼴로 표시되며 특정 한글 폰트를 지정한 것은 아닙니다.

로고 `/brand/motnani-admin-wordmark.png`의 글씨는 이미지입니다. Pretendard로 입력한 텍스트가 아니며, 코드만으로 로고 원본 서체명을 확정할 수 없습니다.

## 5. 글자 크기·굵기

| 용도 | 코드 | 크기 | 굵기 |
| --- | --- | --- | --- |
| 관리 페이지 제목 | `.page-title` | 모바일 28px / 768px 이상 36px | 800 |
| 등록·편집 팝업 제목, 가입 제목 | `text-2xl font-bold` | 24px | 700 |
| 확인 팝업·내 정보·비밀번호 제목 | `text-xl font-bold` | 20px | 700 |
| 농가 카드 제목 | `text-lg font-extrabold` | 18px | 800 |
| 기본 본문·검색 입력·메뉴 | 기본 / `text-base` | 16px | 기본 400 / 메뉴 700 |
| 설명·표·폼 라벨·알림 | `text-sm` | 14px | 400·600·700, 요소별 지정 |
| 메뉴 구역명·도움말·배지·ID | `text-xs` | 12px | 400·600·700, 요소별 지정 |
| 닫기 × 등 문자 아이콘 | `text-3xl` | 30px | 요소별 지정 |
| 체험 운영 페이지 제목 | 별도 크기 지정 | 모바일 22px / 768px 이상 28px | 800 |

사용 중인 굵기: `font-normal` 400, `font-semibold` 600, `font-bold` 700, `font-extrabold` 800.

기본 행간은 1.7이며, `text-*` 클래스는 Tailwind의 자체 행간을 함께 적용합니다. 예를 들어 `text-sm`은 20px, `text-base`는 24px입니다. 전역 h1~h3는 행간 1.3·자간 -0.01em, `.page-title`은 자간 -0.02em입니다.

| 상품·레시피·이벤트·휴지통 목록 | 흰 표와 연회색 헤더, 회색 구분선, 14px 중심. 수정은 브랜드색, 삭제는 danger색 |

## 7. 현재 혼용되는 부분

- 성공색은 브랜드 토큰이 아니라 Tailwind 초록색을 직접 사용합니다.
- 오류는 `danger`와 `red-700`이 함께 사용됩니다.
- 입력 테두리는 `line`과 `field-border` 두 종류입니다.
- 표 헤더 `gray-50`과 본문 배경 `sand`는 서로 다른 연회색입니다.
- 따라서 현재 화면을 그대로 재현하려면 모든 회색·빨강을 한 값으로 통일하지 않아야 합니다.
