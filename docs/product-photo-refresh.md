# 상품별 사진 교체

2026-10-13, C 이상재.

## 변경 이유와 결과

기존 갤러리는 채소 21종의 공통 세 장을 사용해 같은 채소 상품들에 사진이 반복됐습니다. 귤은 탁한 색감·상한 듯 보이는 사진을 포함한 세 장이 모든 상품에 순서만 바뀌어 표시됐습니다.

활성 상품 67개의 사진 구성을 상품 ID 기준으로 나눴습니다. 각 상품에 세 장씩 총 201개 표시 자리를 연결하며, 실제 사진은 154장입니다. Pinterest에서 새로 고른 99장과 검수 후 유지한 기존 사진 55장입니다. 대표사진 67장은 파일 내용 기준으로 모두 다르고, 순서를 무시해도 동일한 세 장 구성이 되는 상품은 없습니다. 같은 농가의 같은 품목 안에서만 일부 보조 사진을 공유합니다. 서로 다른 농가는 사진 세 장 중 어느 한 장도 공유하지 않습니다.

귤은 탁한 색감의 기존 사진 두 장을 제외하고 잎이 달린 원물·흰 배경의 단면·그릇에 담긴 사진 등으로 교체했습니다. 고추는 풋고추·홍고추·청양고추·모둠의 색상에 맞춰 연결했습니다. 요리·큰 글씨·워터마크·그림·다른 품목이 섞인 후보는 제외했고 일부 원물 손질·재배 모습은 보조 사진으로 사용합니다. 후보를 품목별 검수표로 보고 실제 연결 결과도 대조했습니다.

## 연결 구조

- `src/data/product-photo-overrides.json`: 상품 ID → 사진 세 장. 첫 장이 대표사진입니다.
- `src/lib/product-gallery.ts`: 상품별 구성을 먼저 선택하고, 아직 지정하지 않은 상품은 기존 채소별 묶음과 DB 대표사진으로 처리합니다.
- 공통 상품 카드에는 상품 ID를 전달합니다. 목록·홈·레시피의 판매 상품 카드·상세가 같은 구성을 사용합니다.
- 상품 서비스의 대표사진과 장바구니·찜의 대표사진도 같은 선택 함수를 사용합니다. Mock과 Supabase 모두 표시 사진에 적용되며 DB의 기존 `image_path`는 보존합니다. SQL 적용은 필요하지 않습니다.
- 목록의 기존 2초 자동 전환·0.7초 페이드·호버/포커스 정지와 상세의 이전·다음·썸네일 조작은 유지합니다.

## 출처와 파일

Pinterest 공개 핀에서 확인한 이미지의 원본 바이트를 배포 파일에 포함했습니다. 원본 포맷을 보존하고, 크기가 작은 후보는 제외했습니다. 새 파일 위치는 `public/images/products/curated/<vegetableId>/<hash>.<extension>`입니다. 원본 사진을 늘리거나 워터마크를 지우는 편집은 하지 않았습니다.

[사진 출처 기록](product-photo-sources-20261013.json)에 핀 URL·Pinterest 이미지 URL·연결된 원문 URL·핀 게시자·크기·포맷·SHA-256·연결 상품을 기록했습니다. Pinterest 게시자는 원작자와 다를 수 있으며 무료 라이선스나 이용 허락을 확인한 사진으로 표시하지 않습니다. 기존 사진의 출처는 [image-sources.md](image-sources.md)를 유지합니다. 가상 상품의 참고 사진이며 각 농가·포장 수량·손상 상태를 직접 촬영한 증빙 사진은 아닙니다.

### 농가 간 보조사진 중복 수정

이전 버전은 대표사진과 세 장 구성의 중복만 검사해 자동 전환 중 다른 농가에 같은 보조사진이 나타났습니다. 상품의 `farmName`으로 사진을 다시 나누고 Pinterest에서 추가 검수한 사진을 연결했습니다. 사진 출처 기록에 상품의 농가와 각 사진의 사용 농가를 추가했습니다. 실제 파일 SHA-256을 기준으로 다른 농가가 한 사진을 공유하면 테스트가 실패합니다. 같은 농가의 동일 품목만 보조사진을 공유하며 67개 대표사진과 전체 세 장 구성의 중복 방지도 유지합니다.

### 레시피 상세 카드 경로 수정

Vercel 레시피 상세의 연결 상품 카드에서 당근 공통 사진이 반복되는 문제가 추가로 확인됐습니다. 상품 사진 데이터에는 농가 간 공유가 없었지만, 레시피 카드가 `productId`를 전달하지 않아 채소 공통 사진으로 fallback됐습니다. 모든 공통 상품 카드의 `productId`를 필수로 바꾸고 레시피 상세에서도 전달합니다. 담기 버튼 노출은 `showQuickAdd`로 분리해 레시피 카드의 기존 구성은 유지합니다. 실제 레시피 페이지와 공통 카드를 함께 실행하는 회귀 테스트가 수정 전 실패하고 수정 후 통과했습니다. 당근 라페 상세의 연결 상품 사진 9장이 각각 지정된 갤러리와 일치하는 것을 로컬 화면에서 확인했습니다.
