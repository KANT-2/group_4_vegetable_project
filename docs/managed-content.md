# 관리자와 고객 콘텐츠 연결

관리자 상품·레시피·농가·혜택/이벤트 변경은 `var/managed-content/catalog.json`에 저장됩니다. 관리자와 고객은 같은 서버 저장소를 읽습니다. 브라우저 새로고침과 단일 Node 서버 재시작 이후에도 유지됩니다.

- 관리자 저장 API: `/admin/api/content` (관리자 인증과 동일 출처 확인)
- 고객 공개 조회: `/api/managed-content` (비공개 이벤트·휴지통 원문 제외)
- 변경 감지: 3초 간격의 버전 조회와 창 포커스 시 확인. 변경 시 서버 페이지 갱신
- 동시 편집: revision 불일치 시 409로 거부하고 재조회 안내
- 판매 중: 목록 공개·구매 허용
- 품절: `isActive=true, stock=0`. 목록·상세 공개, 장바구니 추가·기존 모의 결제 Action 차단
- 판매 중지: 고객 목록·상세 조회에서 제외
- 기존 주문에 복사된 상품명·가격·배송지 정보는 변경하지 않음

이 저장소는 가상 프로젝트의 **단일 서버 파일 기반 영속 저장**입니다. Supabase 상품 원본이나 FastAPI의 상품 DB를 수정하지 않으며 다른 팀원 PC와 파일이 자동 공유되지는 않습니다. 여러 서버·서버리스 배포에서는 공유 DB 저장소로 교체해야 합니다. 가격 원본과 재고 차감이 주문 백엔드와 원자적으로 연결되도록 하는 작업은 상품·주문 담당자와 별도 통합이 필요합니다. 기존 모의 결제 DB RPC는 DB 가격으로 계산하므로 실제 DB 모드에서는 관리자 가격과의 완전한 동기화 전 판매용으로 사용하지 않습니다.

공유 DB 마이그레이션은 이 변경에서 실행하지 않습니다. 로컬 데이터 파일은 git에서 제외됩니다.
