## 못난이마켓 — AX2 React/Next.js 6팀

모양·크기 등 외형 차이로 일반 유통에서 판매하기 어려운 비규격 농산물을 합리적인 가격으로 소개하는 쇼핑 서비스입니다. 상품의 상태·채소 보관과 손질 정보·활용 레시피·농가 이야기를 연결하여 구매에서 식탁까지 이어지는 경험을 만듭니다. 외형상 비규격과 부패·안전 문제는 구분합니다.

### 목표와 구현 범위

- 소비자가 비규격 농산물의 가격·상태·활용법을 확인하고 상품을 탐색할 수 있도록 합니다.
- PC와 모바일에서 동일한 핵심 기능을 사용할 수 있는 반응형 웹을 구현합니다.
- 메인, 농가·브랜드 이야기, 레시피 목록·상세, 상품 목록·상세, 채소 정보, 로그인, 마이페이지, 장바구니·찜의 10개 화면 유형을 구성합니다.
- 찜과 장바구니는 하나의 /cart 화면 안에서 탭으로 통합합니다.
- 채소 일반 정보와 개별 판매 상품의 상태·가격·수량을 구분하여 표시합니다.
- 레시피 목록과 상세, 컴포넌트 및 조회 기능은 A가 한 도메인으로 담당합니다.
- 로그인·세션·사용자별 장바구니/찜 저장 및 RLS로 개인 데이터를 구분합니다.
- 주문 생성·모의 결제·본인 주문 내역은 README의 선택 과제로, 현재 #191에서 C 이상재의 추가 담당 범위로 지정되었습니다. 기본 기능과 구분하여 구현·검증합니다. 실제 결제·배송·환불과 AI 레시피 추천은 기본 범위에서 제외합니다.

### 진행 기록 및 완료 기준

- Redmine은 팀 프로젝트의 범위·담당·진행 상태를 관리합니다. 개인 연습 과제와 구분하여 이 프로젝트의 WBS 아래 등록합니다.
- 작업 시작/진행/완료 시 담당 일감의 상태·진척도와 댓글을 갱신합니다. 댓글에는 한 일, 막힌 점, 다음 작업, GitHub 커밋 또는 PR 링크를 남깁니다.
- 노션 개인 일지는 담당자별 표에서 작성하고 전체보기에서는 전원 기록을 확인합니다. 역할·문제·접근·결과와 관련 일감·PR 링크를 기록합니다.
- GitHub에는 기능 브랜치에서 작업하고 PR로 공유합니다. 관련 커밋·PR 설명에 Redmine 일감 번호를 연결합니다. main에 임의로 직접 병합하지 않습니다.
- 완료는 실제 화면 동작·오류/빈 상태·개인 데이터 분리·모바일 터치 및 레이아웃·통합 확인 결과를 기준으로 합니다. 문서·폴더·DB 자료 준비를 서비스 전체 완료로 표시하지 않습니다.
- 시작일·마감일·추정시간·배포 주소는 팀이 실제로 확정한 뒤 기록합니다. 임의 일정이나 완료율을 입력하지 않습니다.
