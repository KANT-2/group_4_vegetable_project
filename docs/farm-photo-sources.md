# 농가 이야기 실제 사진 출처

농가 카드와 상단 배너의 큰 사진은 Wikimedia Commons의 실제 농장 사진입니다. 시연 농가의 실제 인물·현장이 아니며, 작물에 맞는 풍경을 골라 썼습니다. 출처는 농가 이야기 페이지 아래 접힌 "사진 출처"에 표시합니다.

제주 귤밭과 상단 배너, 기존 토마토 온실·마을 밭 사진은 한국에서 찍은 사진입니다. 감자·당근·고구마·양배추·대파·오이·유리온실·표고 사진은 좋은 한국 사진을 찾지 못해 해외에서 찍은 사진을 썼습니다.
