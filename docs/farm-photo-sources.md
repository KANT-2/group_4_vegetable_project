# 농가 이야기 실제 사진 출처

상단과 카드의 큰 사진은 한국 농촌의 실제 촬영 사진입니다. 시연 농가의 실제 인물·현장이 아닙니다. 상품 사진은 작은 썸네일로 구분합니다. 출처는 페이지 아래 접힌 사진 출처에 표시합니다.

| 사진                                                                                                                                  | 작가             | 사용 조건                                                 |
| ------------------------------------------------------------------------------------------------------------------------------------- | ---------------- | --------------------------------------------------------- |

| [원본](https://commons.wikimedia.org/wiki/File:2020-05-09_13.17.37_tomato_greenhouse.jpg) · `/images/farms/greenhouse.webp`           | Choi Kwang-mo    | [CC0](https://creativecommons.org/publicdomain/zero/1.0/) |
| [원본](https://commons.wikimedia.org/wiki/File:Korea-Anseong-004.jpg) · `/images/farms/fields.webp`                                   | Barnkim          | [CC BY 3.0](https://creativecommons.org/licenses/by/3.0/) |

모바일 전송량을 줄이기 위해 최대 1600px WebP로 인코딩했습니다. 표시 영역에 맞춰 크롭하며 작가·원본·라이선스 링크를 유지합니다. 정적 이미지로 DB 컬럼 변경은 없습니다. 실제 참여 농가의 사진을 확보하면 각각 교체할 수 있습니다.
